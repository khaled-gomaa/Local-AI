# Scanning Tools

This skill is a methodology reference for discovery tooling.

Organize tools by:
- DNS/subdomain discovery
- HTTP probing
- URL/content discovery
- service discovery
- technology fingerprinting
- cloud/external attack-surface intelligence

Before any active action:
- verify authorization
- minimize requests
- respect rate limits
- keep a record of scope and tool settings

The skill itself does not launch scanners automatically.

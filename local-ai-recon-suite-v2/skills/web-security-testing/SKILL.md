# Web Security Testing

Use after scope is known.

Phase 1 — surface mapping:
- map host/path/method/parameters
- identify application technologies from evidence
- discover endpoints/subdomains only where authorized
- record uncertainty

Phase 2 — security context:
- use RAG to find closely related technical cases
- inspect authentication, session, and access-control context

Phase 3 — reporting:
- distinguish observed facts, hypotheses, and recommendations
- link to retrieved source URLs
